# 05. 사용자 매뉴얼

> 대상: 여행자(앱·웹을 쓰는 사람)
> 운영자용 내용은 [04 운영 매뉴얼](04-운영-매뉴얼.md)을 보세요.

## 0. 이 앱으로 할 수 있는 일

어느 나라 여행이든 **일정·티켓·준비물·회화**를 미리 정리하고, 여행 중에는 휴대폰에서 **오프라인으로** 보고, **지도·메모·사진·환율·긴급 번호**를 쓸 수 있습니다.

| 어디서 | 무엇을 |
|--------|--------|
| **사용자 웹**(PC) | 여행 만들기, 일정·장소·티켓·회화·준비물을 넉넉한 화면에서 입력 |
| **모바일 앱** | 여행 중 일정 보기, 지도, 주변 탐색, 메모·사진, 환율, 회화, 긴급 번호, 공유 |

같은 계정으로 로그인하면 웹과 앱의 데이터가 같습니다.

---

## 1. 시작하기

### 1-1. 가입·로그인
1. 앱(또는 웹)을 열고 **회원가입** 탭에서 이메일·비밀번호를 입력합니다.
2. 비밀번호는 **8자 이상, 영문과 숫자를 각각 1개 이상**, 이메일과 같지 않아야 합니다.
3. 인증 메일을 보냈다는 안내가 나오면 메일의 링크를 누른 뒤 **로그인**하세요.
4. 운영자가 **임시 비밀번호**를 주었다면, 로그인 직후 새 비밀번호를 정하는 화면이 먼저 나옵니다.

### 1-2. 첫 여행 만들기 (앱)
**도구 → 설정 → 새 여행** 에서 이름·나라·도시·기간을 입력하고 저장합니다.
- 나라는 **여러 개** 고를 수 있습니다(예: 스페인, 포르투갈).
- 저장하면 화면 아래에 "새 여행을 만들었어요"가 잠깐 나타났다 사라집니다.
- 기간을 정하면 **일차가 자동으로 만들어집니다.** 기간을 줄이면 범위 밖 날짜의 일정은 삭제되니 주의하세요.

---

## 2. 홈 화면

- **상단**: 여행 이름, 나라의 **현지 시간**, **D-day**(출발까지 남은 날 / 여행 중 / 완료), 기간. 여행 중에는 `총 N일 중 n일차` 가 눈에 띄게 표시됩니다.
- **여행 선택 칩**: 여러 여행이 있을 때 탭해서 바꿉니다. **진행·예정 여행이 가까운 순으로 먼저, 완료된 여행은 뒤에** 나옵니다. 여기서 고른 여행이 **모든 화면(일정·지도·준비·티켓…)의 기준**이 됩니다.
- **다음 일정 한 줄**(여행 중일 때만): 시간 + 장소. 장소를 누르면 상세, 오른쪽 `›` 를 누르면 전체 일정.
- **준비물 진행 막대**, **빠른 실행**(일정·지도·티켓·준비물·환율·회화·메모·사진).
- **완료된 여행**을 고르면 여행 일수·방문 장소·메모·사진 통계와 **추억 돌아보기** 가 나옵니다.

---

## 3. 여행 탭

### 3-1. 일정
1. 위쪽 **날짜 스트립**에서 날짜를 고릅니다(일정이 있는 날은 점 표시).
2. **편집**을 눌러 장소를 추가·순서 변경·시간(24시간제 `09:30`)·메모를 입력합니다.
3. **장소 추가** 창은 다음 탭으로 이루어져 있습니다.

| 탭 | 설명 |
|----|------|
| **내 장소**(기본) | 내가 만든·가져온 장소. 검색·분류 필터. 맨 아래 **새 장소 만들기** |
| **추천 관광지** | 운영자가 좌표까지 등록해 둔 관광지. 나라 칩으로 고르고, **다른 나라**에서 전 세계 나라를 검색 가능. 도시·분류 필터 |
| **웹에서 찾기** | 추천이 없거나 부족할 때, 버튼을 누르면 Google 지도에서 해당 나라/도시의 인기 관광지·맛집 등을 찾아 줌 → 눌러서 담기 |

4. **새 장소 만들기**: ① 이름·주소를 검색해 **위치 찾기** → ② 후보를 고르면 **좌표와 지도 미리보기**가 보임 → ③ 이름·분류 확인 후 저장. 위치를 못 찾으면 `위치 없이 이름만 저장`도 가능하지만 **지도에는 표시되지 않습니다.**
5. 마지막에 **저장**을 누르면 "일정을 저장했어요"가 나타납니다. 저장하기 전의 삭제 표시(삭제 예정)는 `되돌리기` 가능합니다.

### 3-2. 준비
- 준비물을 **체크**하면 챙김 처리, `+/-` 로 수량을 바꿉니다. 분류(서류·의류·전자기기·세면·약·기타)별로 접고 펼 수 있습니다.
- 모두 챙긴 분류는 자동으로 접힙니다. 이름을 입력해 항목을 추가합니다. (사용자 웹에는 자주 쓰는 준비물 추천 버튼이 있습니다.)

### 3-3. 티켓
항공·호텔·티켓 정보(예약번호 등)를 저장해 두고 오프라인에서도 꺼내 봅니다. 저장·삭제가 가능합니다.

### 3-4. 공유 — 링크로 나누기
**보내기**
1. 여행 → **공유** 에서 공유할 항목(일정·준비물·회화 등)을 고르고 **링크 만들기**.
2. 만들어진 `honeymoon://share/…` 링크를 메신저 등으로 전달합니다. **앱 전용 링크**이며 **14일 뒤 만료**됩니다.
3. 내가 만든 링크는 목록에서 언제든 **삭제(철회)** 할 수 있습니다.

**받기**
1. 링크를 열면 앱이 **가져오기 화면**으로 열립니다(앱 설치·로그인 필요).
2. **가져올 항목**을 고르고, 적용 방식을 선택합니다.

| 적용 방식 | 동작 |
|-----------|------|
| 새 여행으로 | 받은 내용을 새 여행으로 만듦(가장 안전) |
| 합치기 | 내 여행에 일정·준비물을 더함(중복은 건너뜀) |
| 덮어쓰기 | 내 여행의 선택한 항목을 받은 내용으로 교체(**확인 창**이 뜸) |

> 티켓(예약번호 등)은 기본적으로 공유 항목에서 **꺼져 있습니다.** 필요할 때만 켜세요.

---

## 4. 지도 탭

### 4-1. 일정 지도
- 선택한 여행의 **선택한 날** 장소가 번호 핀(빨간 물방울)으로 표시됩니다.
- 하단 패널의 `‹ ›` 로 날짜를 바꾸고, **위아래로 당겨** 높이를 조절합니다(목록 접기/펼치기).
- **목록에서 장소를 누르면** 그 위치가 (패널에 가리지 않는) **보이는 지도의 가운데**로 이동하고 핀이 커집니다. 길찾기는 파란 `›` 버튼.
- 왼쪽 버튼
  - 📍 **내 위치로**: 현재 GPS 위치로 이동(누르면 잠깐 파란색으로 바뀜). 내 위치는 파란 점으로 표시되고 이동하면 따라갑니다.
  - 📅 **일정 위치로**: 그날 일정 장소가 **모두 보이도록** 맞춥니다.
- 좌표가 없는 장소는 목록에 `위치 없음 · 지도에 표시되지 않아요`로 보입니다. 그날 표시할 장소가 없으면 안내가 3초 뒤 사라집니다.
- 처음 열면 **내 위치** 기준으로 시작합니다(위치 권한 허용 필요).

### 4-2. 주변 탐색
- 현재 위치(없으면 다음 일정/첫 일정 장소) 기준 **약 1.2km** 안에서 찾습니다.
- 위쪽 칩 `관광지 · 식당 · 카페 · 숙소 · 쇼핑` 으로 분류를 바꾸면 같은 기준점에서 다시 검색합니다. 결과는 **가까운 순**이며 거리(m/km)가 표시됩니다.
- 항목을 누르면 장소 상세(위키 소개 등)가 열립니다.

---

## 5. 기록 탭

### 5-1. 메모
- 글을 쓰고 사진·현재 위치를 붙여 저장합니다. **오프라인에서도 저장**되고 인터넷이 연결되면 자동으로 서버에 올라갑니다.
- 삭제하면 서버에서도 삭제됩니다(되돌릴 수 없음).

### 5-2. 사진(추억)
- 여행 사진을 모아 보고, 촬영하거나 갤러리에서 불러옵니다. **사진 원본은 내 휴대폰에만 있고** 서버에는 촬영 시각·위치 정보만 저장됩니다.
- 완료된 여행은 홈에서 **추억 돌아보기**로 볼 수 있습니다.

---

## 6. 도구 탭

| 메뉴 | 사용법 |
|------|--------|
| **환율** | 여행 나라의 통화가 자동으로 잡힙니다(원·달러 함께). 금액을 입력하면 변환. 최신 환율로 **갱신**하거나, 통화별로 **직접 입력**한 환율을 저장 |
| **회화** | 상황별 문장(한국어 ↔ 현지어)을 저장하고 **읽어주기**. 음성 언어는 코드 입력 대신 **목록에서 선택** |
| **긴급** | 나라별 긴급 번호 확인, 내 비상 연락처 저장 |
| **설정** | 여행 만들기·수정·삭제(여행이 많으면 검색, 완료 여행은 아래 `다녀온 여행` 접기), 앱 버전, 서버에서 최신 데이터 불러오기, 이 기기 저장 데이터 비우기, 비밀번호 변경, 로그아웃 |

## 7. 사용자 웹(PC) 사용법

주소: 운영자가 안내한 사용자 웹 주소 → 같은 계정으로 로그인.

| 메뉴 | 설명 |
|------|------|
| **대시보드** | 여행·장소·바우처·회화·준비물 개수, 등록된 여행 목록(상태: 여행 중 / D-n / 완료) |
| **여행 계획** | 여행 목록·**새 여행 계획**. 한 여행을 열면 탭: 개요 · 일차 구성 · 장소 · 바우처 · 준비물 · 회화 |
| **장소** | 내 장소 목록(분류 필터 `전체/맛집/관광/숙소/교통`, 검색), 지도에서 좌표 선택 |
| **바우처 / 회화 / 준비물** | 목록 관리(여행별 필터, 검색) |

**장소 등록 방법 3가지**
1. **직접 등록**: 이름·분류·주소 입력 후 **지도에서 위치 선택** — 나라를 골라 그 나라 안에서 검색하면 결과가 더 정확합니다.
2. **추천 관광지에서 찾기**: 나라 칩 / **다른 나라**(전 세계) / 분류 칩(전체 포함) / 검색 → `내 장소에 담기`.
3. **웹에서 한 번에 찾기**: 나라(와 도시)를 고르고 찾을 분류(맛집·숙소·관광지·교통)를 켠 뒤 **한 번에 조회** — 분류마다 최대 30건. 항목별 `내 장소에 담기` 또는 `이 분류 모두 담기`.

저장·수정 결과는 화면 아래에 잠깐 나타났다 사라집니다.

## 8. 자주 묻는 질문 / 문제 해결

| 질문/증상 | 답 |
|-----------|----|
| 다른 여행을 보고 싶어요 | **홈**에서 여행 칩을 선택하세요. 일정·지도·준비·티켓이 모두 그 여행으로 바뀝니다 |
| 지도에 핀이 안 보여요 | 그 장소에 **좌표가 없어서**입니다. 일정에서 장소를 `위치 찾기`로 다시 만들거나, 추천/웹에서 찾은 장소를 담으세요 |
| 내 위치가 안 나와요 | 휴대폰 **위치 권한**과 GPS 를 켜 주세요 |
| 추천 관광지에 우리 나라가 없어요 | "준비 중"인 나라입니다. **웹에서 찾기**로 직접 담거나 **새 장소 만들기**를 쓰세요 |
| 오프라인인데 쓸 수 있나요? | 최근에 본 일정·티켓·회화·준비물과 메모 작성은 가능합니다. 지도·검색·환율 갱신은 인터넷이 필요합니다 |
| 웹에서 고쳤는데 앱에 안 보여요 | 앱 **설정 → 서버에서 불러오기** 하거나 앱을 다시 여세요 |
| 링크를 열었는데 가져오기가 안 돼요 | 링크가 **14일이 지나 만료**됐거나 삭제됐을 수 있어요. 보낸 사람에게 새 링크를 요청하세요. 앱에 로그인되어 있어야 합니다 |
| 비밀번호를 잊었어요 | 운영자에게 요청하면 임시 비밀번호나 재설정 메일을 받을 수 있습니다 |
| 일정이 사라졌어요 | 여행 **기간을 줄이면** 기간 밖 날짜의 일정은 삭제됩니다 |
| 휴대폰을 바꿨어요 | 같은 계정으로 로그인하면 여행 데이터가 복원됩니다. 사진 원본은 옮겨지지 않습니다 |

## 9. 개인정보와 안전

- 내 여행·메모 내용은 **내 계정으로만** 볼 수 있습니다(운영자도 내용은 볼 수 없고 가입·접속 현황만 확인).
- 접속 기록(시각·기기·IP)은 서비스 운영과 보안을 위해 일정 기간 보관됩니다.
- 공유 링크를 받은 사람은 링크에 포함된 항목을 볼 수 있으니, 예약번호 같은 민감한 정보는 공유하지 마세요.
