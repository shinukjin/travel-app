# 03. 소스 설명

> 폴더·파일별로 "무슨 일을 하는지"를 설명합니다. 코드를 고치기 전에 해당 파일의 역할과 **주의점**을 먼저 확인하세요.
> 짝 문서: [01 아키텍처](01-시스템-아키텍처.md) · [02 데이터베이스 설계](02-데이터베이스-설계.md)

## 0. 저장소 구조

```
travel/
├─ mobile/      Expo(React Native) 앱 — 여행 중 사용
├─ web/         Vue 3 사용자 웹 — 여행 계획 입력
├─ admin/       Vue 3 운영 콘솔 — 운영자 전용
├─ supabase/    SQL 마이그레이션 (0001~0007)
├─ backend/     (사용 안 함) 예전 Spring Boot — 이전 스크립트용 보관
├─ docs/        문서 (이 폴더)
├─ .claude/     Claude Code 설정·스킬 (ui-ux-pro-max 등)
├─ CLAUDE.md    작업 지침 (한국어, 커밋·보안 규칙)
└─ .env         비밀 값 (커밋 금지)
```

### 꼭 지킬 규칙 (CLAUDE.md 요약)
1. `web/src/supabaseApi.js` 와 `mobile/src/supabaseApi.js` 는 **동일 파일** — 한쪽을 고치면 다른 쪽도 같게 고친다.
2. 사용자 웹(`web/`)에는 **운영 메뉴를 넣지 않는다.** 관리자 기능은 `admin_*` SQL 함수로만.
3. Supabase 는 **anon 키만**. `service_role` 키 금지. `.env` 커밋 금지.
4. 커밋은 요청할 때만, 메시지·주석은 한국어. 범위 최소화, 기존 패턴(`Screen`/`HubShell`/`theme.js` 토큰) 유지.

### 1-7. 모바일 코딩 시 주의점
- 플랫폼별 파일은 `*.web.js` / `*.native.js` 로 분리(지도 등). 한쪽만 고치지 않도록 확인.
- 색·간격은 `theme.js` 토큰만 사용(터치 영역 ≥ 44, 본문 글씨 ≥ 12).
- 버튼(`Pressable`) 안에 버튼을 중첩하지 않는다(웹에서 `<button>` 중첩 오류).
- 검증: `cd mobile && npx expo export --platform android --output-dir ../.tmp-export` 후 폴더 삭제.
